# Filtering options in Blazor TreeGrid

This sample explains how to work with the filtering options available in the Syncfusion Blazor TreeGrid component (Blazor WebAssembly, .NET 10), including hierarchy filter modes and the Excel-like filter.

**Documentation**: https://help.syncfusion.com/grid-sdk/blazor/tree-grid/getting-started

**Online example**: https://blazor.syncfusion.com/demos/tree-grid/default-filtering

## Prerequisites

* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Visual Studio 2022 / Visual Studio Code

## Project structure (.NET 10)

```
├── App.razor
├── _Imports.razor
├── Program.cs
├── TreeGridFilteringOptions.csproj
├── Layout/               # MainLayout
├── Pages/                # Home (Tree Grid filtering sample), NotFound
├── Properties/           # launchSettings.json
└── wwwroot/              # index.html, css, bootstrap
```

## How to run the project

* Checkout this project to a location in your disk.
* Restore the NuGet packages by rebuilding the project.
* Run the project.
